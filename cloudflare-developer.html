Case study: how this site runs on Cloudflare

> Hosting. Hand-coded HTML, CSS and JavaScript deployed to Cloudflare Pages from GitHub. Every push to the main branch builds a preview and goes live automatically. No server, no database, nothing to patch.

> Contact form. The form posts to a Worker on api.stackedbydan.dev. Turnstile protects it from bots, and its script only loads when a visitor scrolls near the form, so it doesn't slow down the first page view.

> Security. A _headers file sets a Content Security Policy, HSTS, frame and MIME protections and a locked-down Permissions-Policy on every response.

> Speed. Brotli compression, year-long immutable caching for versioned CSS and JS, non-blocking fonts and no page-builder overhead. Demo sites run on their own subdomains of the same zone.
